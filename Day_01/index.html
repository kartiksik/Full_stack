Bash commands that I have learnt

1. mkdir

-> The mkdir command creates a new folder in the current directory or in any specific path you mention.

Syntax: mkdir "foldername"

Example: mkdir niceone

Output: Creates an empty folder in the current directory named "niceone"

2. touch

-> The touch command creates a new empty file in the current folder.

Syntax: touch "filename"

Example: touch wild.txt

Output: Creates a new empty file in the current folder named "wild.txt"

3. vim

-> The vim command opens a file in the Vim text editor inside the terminal.

Syntax: vim "filename"

Example: vim wild.txt

Output: Opens the wild.txt file in the Vim editor.

4. cd

-> The cd command changes the current working directory to the selected directory.

Syntax: cd foldername

Example: cd badone

Output: Changes the working directory to the "badone" folder.
